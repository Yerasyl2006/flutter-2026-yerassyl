# Practice 9 — Put It High, Subscribe Low

## Что делает приложение

Магазин содержит шесть книг. Add добавляет книгу в общую корзину, показывает Added и SnackBar. Значок показывает число разных книг и сумму. В Cart можно увеличивать количество, удалять книги и очищать корзину после подтверждения. Поиск фильтрует название и автора. Итог можно свернуть.

## Level 1 — lifted

Версия с StatefulWidget над MaterialApp сохранена отдельным коммитом `lifted`.
Для передачи total изменены 2 конструктора: BooksScreen и CartBadge. Изменены 3 файла: main.dart (вычисление и передача), books_screen.dart (приём и передача), cart_badge.dart (приём и показ).
Ожидаемый вывод при одном Add: 7 строк — BooksScreen build и 6 строк row. Это расчёт по коду, а не замер DevTools. Перестроения зависят также от видимости маршрута и оптимизаций Flutter.

## Level 2 — модель

Cart использует только foundation.dart и собственный Book. Приватная Map хранит количества. items возвращает неизменяемый список. add возвращает false для дубликата и не уведомляет; успешные изменения вызывают notifyListeners. Тест проверяет защиту списка, уведомления, сумму, количества и результат 1 книга / 3100 ₸ после удаления первой книги.

## Level 3 — provider

ChangeNotifierProvider(create: ...) находится над MaterialApp. Конструкторы экранов не получают корзину. read используется в обработчиках. Consumer получает объект непосредственно в builder.

Ошибка watch в обработчике (диагностический текст provider):
`Tried to listen to a value exposed with provider, from outside of the widget tree.`
Исправление — read в обработчике. Эта намеренная поломка не оставлена в приложении; текст приведён для объяснения, ручное воспроизведение не заявляется.

Ошибка read в build: сообщения исключения нет. Значение остаётся прежним до другого независимого перестроения; например, badge может оставаться 0. Это отсутствие подписки, а не ошибка компиляции.

## Level 4 — измерения

Автоматический widget-тест evidence_test.dart меняет количество три раза с отдельным pump после каждого изменения:

| Подписка | Перестроения после трёх increment |
| --- | --- |
| watch на count в контрольном виджете | 3 |
| select на count в настоящем CartBadge | 0 |
| select после удаления книги | 1 |

Это измерения widget-теста, не ручной замер DevTools. Начальная сборка исключена. debugPrint('badge build') оставлен для ручной проверки. Сумма в badge подписана отдельным дочерним виджетом: она обновляется при изменении количества без перестроения самого счётчика. Каждая строка Books подписана на bool наличия своей книги. Consumer итоговой строки повторно использует const child с иконкой и подписью.

## Level 5 — Where does it live?

- Корзина — provided: общие данные для двух маршрутов и badge.
- Текст поиска — ephemeral: нужен только BooksScreen, хранится в State.
- Развёрнут ли итог — ephemeral: локальная настройка CartScreen.
- Режим темы при наличии переключателя — lifted над MaterialApp; для доступа многих независимых экранов его можно сделать provided.

SnackBar решается в обработчике по bool от add. Диалог очистки принадлежит экрану; после await проверяется context.mounted. Модель не знает об интерфейсе.
