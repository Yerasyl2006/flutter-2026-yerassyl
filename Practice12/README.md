# Practice 12 — Survive a Restart

Flutter-приложение для Android и iOS на основе Practice 11. Список приходит с JSONPlaceholder. Вход учебный: используйте `student@example.com` / `12345678`.

## Запуск на Windows

```powershell
Set-Location C:\dev\Practice12
flutter pub get
flutter devices
flutter run -d emulator-5554
```

Подставьте ID своего устройства из `flutter devices`. Для этой практики нужен Android-эмулятор или телефон: проверка разрешений камеры и файлов выполняется на устройстве.

## Запуск в Chrome

```powershell
Set-Location C:\dev\Practice12
flutter pub get
flutter run -d chrome --web-port 8122
```

Для проверки сохранения данных открывайте приложение с того же адреса и порта в том же профиле Chrome. На вебе список и аватар хранятся в данных сайта. Проверить баннер можно в уже открытом приложении: сначала дождитесь списка, затем в DevTools → Network выберите **Offline** и потяните список вниз для обновления. Верните **No throttling** и нажмите **Retry**. Диалог после запрета системного доступа к камере проверяется на Android или iOS; в Chrome выбор фото открывает браузерный диалог.

## Что показать на защите

1. Войдите, дождитесь списка, откройте **Settings**, включите **Dark mode** и выберите город. Полностью закройте приложение и откройте снова. Вход, тёмная тема и фильтр должны сохраниться. Для проверки всех десяти пользователей верните **All cities**.
2. В Flutter DevTools откройте **Network**, обновите список и найдите `GET /users`. В заголовках запроса будет `Authorization: Bearer tok_…`. Кнопка копирования учебного токена доступна в карточке пользователя в debug-сборке. **Settings → Sign out** удаляет токен.
3. Загрузите список онлайн, включите авиарежим (и отключите Wi-Fi, если он остался включён), закройте и снова откройте приложение. **Saved data · no connection** появляется над сохранённым списком. Нажмите **Retry** без сети и затем с сетью. Снимок баннера сохраните как `screenshot_offline_banner.png`.
4. Откройте **Profile → Take photo** и дважды откажите в доступе. Если устройство больше не показывает системный запрос, приложение предлагает **Open settings**. Снимок этого диалога сохраните как `screenshot_permission_dialog.png`. Проверьте **Choose photo** и перезапуск после выбора.
5. Нажмите email, телефон и сайт в карточке. Если на эмуляторе нет подходящего приложения, появится сообщение.
6. Для сдачи добавьте проект, `NOTES.md`, `pubspec.lock` и оба скриншота в свой учебный GitHub-репозиторий.

```powershell
dart format .
flutter analyze
flutter test
flutter pub outdated
```

На iOS используйте Mac с Xcode и CocoaPods; снимок с камеры проверяйте на физическом устройстве.
